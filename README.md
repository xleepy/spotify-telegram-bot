### Spotify telegram bot
Simple spotify telegram bot which is deployed with heroku
Usage:
- type in telegram @xleepy_bot `spotify share url`

### Instagram

Public Instagram videos use anonymous browser impersonation. The handler does not
load login cookies or yt-dlp configuration files. Instagram can still restrict
anonymous requests. Images and carousels are not supported.

`npm install` installs an official standalone yt-dlp build with `curl-cffi`.
